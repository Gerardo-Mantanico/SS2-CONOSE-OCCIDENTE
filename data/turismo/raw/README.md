# Datos crudos de Turismo

Colocar aqui archivos descargados desde fuentes oficiales o institucionales antes de ser transformados.

Archivos sugeridos:

- `destinos_turisticos.csv`: catalogo de destinos por fuente.
- `patrimonio_turistico.csv`: relacion de destinos con patrimonio UNESCO/nacional/intangible.
- `metricas_destino.csv`: metricas futuras de visitantes, busquedas, reseñas o interacciones.
- `eventos_usuario.csv`: eventos anonimizados generados por la aplicacion.

La carga curada inicial ya se encuentra en las migraciones SQL de `database/migrations/turismo/`.
